## 설치·실행·검증

Windows는 C++ 개발 도구를 준비해 솔루션을 열고 원하는 시작 프로젝트를 지정한다. Mac은 README의 Clang 명령으로 AI_Test와 L02_Variable을 각각 빌드한다. L01의 scanf_s는 Mac 기본 Clang에서 제공되지 않는다.

이번 문서 작업에서는 현재 소스와 프로젝트·실행 명령·상대 링크를 검토했다. Mac/Apple Clang 21.0.0에서 README 명령으로 AI_Test와 L02를 각각 빌드/실행했고 예상 출력과 종료 코드 0을 확인했다. AI_Test 경고 0개, L02 사용하지 않는 변수/매개변수 경고 5개다. Windows/MSVC 솔루션 빌드·L01 입력 실행은 이번에 확인하지 않았다. 기존 저장소에는 별도의 통과 기록이 없다.

예상 출력: AI_Test는 2행×3열과 시도 1/2/3, L02는 A=1024·B=-130·C=A·Hello. Windows L01의 첫 입력 8/2는 합 10·차 6·곱 16·몫 4·나머지 0이다. L01은 현재 입력 오류와 0 나누기를 처리하지 않는다.
